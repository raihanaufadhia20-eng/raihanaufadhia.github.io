# Personal Portfolio Web Page

Web portofolio pribadi yang responsif dan interaktif dengan tampilan dark mode modern, dilengkapi animasi teks mengetik (*typing effect*) menggunakan HTML, CSS, dan JavaScript.

## Tech Stack
* **HTML5** – Struktur konten web
* **CSS3** – Custom styling, dark theme, & hover animations
* **JavaScript** – Animasi dynamic typing effect

## Struktur Folder
* `index.html` – File utama struktur HTML
* `style.css` – File styling & layout dark theme
* `script.js` – Script logika animasi mengetik
* `README.md` – Documentation file

## Cara Menjalankan
1. Download atau clone repositori ini.
2. Buka file `index.html` langsung di browser (seperti Chrome atau Edge).
